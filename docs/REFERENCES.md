# Референсы — наблюдения и выводы

Проверены публичный HTML и открытие в Chromium, desktop 1440 px и mobile 375 px. Первое открытие внешних страниц в Chromium встретило `ERR_CERT_AUTHORITY_INVALID` из-за доверия сертификатам среды; для чтения публичных страниц повторён запуск с игнорированием этой ошибки. Локальная проверка FutureKinetix выполнялась по HTTP без такого исключения.

Это анализ структуры и техническое наблюдение, а не полная проверка всех страниц и сценариев чужих сайтов. Для мобильных версий подтверждено отсутствие горизонтального переполнения в момент открытия; детальное поведение всех меню/корзин не проверялось.

В обеих desktop/mobile проверках использованы реальные страницы, а не предполагаемые макеты. На ширине 375 px у всех четырёх страниц scrollWidth составлял 375 px. Детальные измерения сеток, весов шрифтов и загрузка всех видео не проводились; точные значения не приписываются референсам.

Новая композиция FutureKinetix самостоятельная: светлая типографическая вводная, товарная поверхность справа, четыре направления, тёмный зимний блок и единый контакт. Нет буквального копирования навигации, палитр или компонентов референсов.
