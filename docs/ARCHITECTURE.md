# FutureKinetix — этап 1

## Исходное состояние

Исходная ветка `main`, коммит `48df4d7`. Рабочая ветка `codex/site-rebuild`. Прежний сайт — шесть готовых HTML-страниц, общий CSS/JS, `.nojekyll`, Python-валидатор. В документации GitHub Pages указан корень основной ветки. Настройки Pages в удалённом аккаунте на этом этапе не менялись. Предыдущая работа `sites/futurekinetix-2026` сохранена отдельно.

## Стек и сборка

Python 3 (только стандартная библиотека) + семантический HTML + CSS Grid/Flexbox + небольшой JS. Нет npm-зависимостей для работы сайта, серверного приложения или клиентского фреймворка. Контент уже присутствует в HTML и доступен без JS.

- `src/layout.html`: общий каркас, шапка, меню, контакты, футер.
- `src/home.html`: секции главной.
- `src/yarbo.html`: прототип продуктовой страницы.
- `data/products.json`: единый источник конфигураций, модулей и выбранных характеристик.
- `assets/site/site.css`: токены, базовые правила, компоненты, адаптивность.
- `assets/site/site.js`: мобильное меню, Escape/закрытие, копирование email.
- `build.py`: рендеринг шаблонов, сборка `dist/`, проверка локальных ссылок и ассетов.
- `index.html`, `yarbo.html`: сгенерированные страницы для совместимости с корневой статической схемой.

Старые `products.html`, `automation.html`, `company.html`, `contacts.html`, `styles.css`, `site.js` не переписаны и не подключены к новой навигации. Старые версии главной/Yarbo доступны в истории Git. В `dist/` включаются только две новые страницы и их ассеты. Новая версия нигде не опубликована.

## Информационная архитектура

Главная: позиционирование → четыре направления → сезонный Yarbo → индивидуальная разработка → области применения → компания/сервис → контакт.

Yarbo: первый экран → устройство модульной системы → зимний сценарий → три конфигурации → два примера оборудования → таблица основных параметров → контакт.

Будущие самостоятельные разделы: другие роботы (категории и карточки), гуманоиды, индивидуальные решения, установка и сервис, компания, контакты. Сейчас соответствующие пункты ведут к работающим секциям главной; незавершённых страниц в новой навигации нет.

Основной коммерческий путь: главная → Yarbo → конфигурация → консультация. Альтернативный: направление → описание задачи → контакт. Запросы идут в почтовый клиент через `mailto:`; форма с фиктивной отправкой не имитируется.

## Дальнейшее развитие

Для нового продукта расширить JSON и добавить шаблон, используя layout и существующие компоненты. Для публикации позднее можно отдать `dist/` в GitHub Pages через отдельный workflow либо сохранить текущую корневую схему. Автодеплой на этом этапе намеренно не добавлен.
