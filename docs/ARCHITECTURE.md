# Архитектура FutureKinetix

Исходная ветка `main`, коммит `48df4d7`. Новая разработка — `codex/site-rebuild`. Предыдущие версии доступны в истории Git; основная ветка не менялась. Настройки GitHub Pages и существующий опубликованный Sites-сайт не изменялись.

## Стек

Python 3, стандартная библиотека; семантический HTML; CSS Grid/Flexbox; небольшой JS для меню и копирования email. Нет клиентского фреймворка и серверного приложения. Контент присутствует в HTML, навигация/контакты работают без JS. Сборка не требует npm.

- `src/layout.html`: общий каркас, навигация, контакты, футер.
- `src/*.html`: содержимое восьми страниц.
- `data/products.json`: конфигурации, модули, основные характеристики Yarbo.
- `data/accessories.json`: оснастка, назначение, цены наблюдений, источники и методика.
- `assets/site/site.css`: токены и общие компоненты.
- `assets/site/site.js`: мобильное меню, Escape/возврат фокуса, копирование email.
- `build.py`: генерация страниц, вычисление средних цен, сборка `dist/`, проверка href/src.
- `docs/visual-qa.cjs`, `docs/interactions.cjs`: браузерная QA; Playwright нужен только для проверки.

Корневые HTML генерируются для совместимости с существующим корневым статическим размещением GitHub Pages. `dist/` содержит только новую сборку и `.nojekyll`. Старые `styles.css`, `site.js` и логотипы сохранены, но в новую сборку не включаются. Автодеплой не добавлялся.

## Информационная архитектура

1. `index.html`: компания в целом → направления → сезонный Yarbo → инженерия → области применения → компания → сервис → контакт.
2. `yarbo.html`: продукт → разные ракурсы → модульность → зимний сценарий → конфигурации → четыре модуля → тележка/щётка/отвал → другие компоненты и цены → сервис → параметры → контакт.
3. `products.html`: территории, доставка, официанты, склад, манипуляторы, уборка, гуманоиды → данные для подбора.
4. `automation.html`: инженерная разработка → зрение, манипуляция, управление → этапы проекта → вопросы.
5. `humanoids.html`: взаимодействие, исследования, прикладные пилоты → ограничения и условия подбора.
6. `service.html`: установка, настройка, обслуживание, поддержка → запуск Yarbo → условия работ.
7. `company.html`: направления и принципы работы.
8. `contacts.html`: подготовка запроса по оборудованию/проекту/сервису → реальные контакты.

Главные пути: задача → направление → консультация; Yarbo → конфигурация/оснастка → подбор; установленный робот → сервис. Отправка запросов через `mailto:`, звонок через `tel:`. Серверная отправка формы не имитируется.

У прицепной оснастки сторонних производителей явно отмечена необходимость проверки совместимости; наличие и характеристики не выдаются за штатную комплектацию Yarbo. Цены показаны как ориентиры выборки, без доставки/установки.
