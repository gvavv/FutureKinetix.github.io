# Дизайн-система

Концепция: технологический минимализм с тёплой светлой основой, графитовой типографикой и лесным зелёным акцентом. Жёлтый остаётся цветом самого Yarbo. Нет декоративных градиентов, свечения и анимированного фона.

Все токены находятся в `:root` файла `assets/site/site.css`.

| Группа | Решение |
|---|---|
| Основа | `#f5f6f2`, белые товарные поверхности |
| Текст | `#202820`, вторичный `#626b62` |
| Действия | `#214b3d`, hover `#15392c` |
| Тёмная секция | `#172a23`, светлый текст, CTA `#dcedbd` |
| Шрифт | Arial / Helvetica / system sans-serif с кириллицей, локальные системные шрифты без сетевого запроса |
| Размеры | 12, 14, 16, 19, 24, 26 px; H2 32–56 px, H1 42–72 px через clamp |
| Начертания | 400/500 для основного текста и заголовков, 600 для действий/меток |
| Интерлиньяж | текст 1.65, заголовки 1.08 |
| Отступы | 4, 8, 12, 16, 24, 32, 48, 64, 96, 128 px |
| Контейнер | максимум 1320 px, адаптивные боковые поля 20–64 px |
| Радиусы | 4 px для кнопок, 8 px для карточек, pill для сезонных меток |
| Тень | только выпадающая навигация; основное разделение — линии и поверхности |
| Состояния | hover, focus-visible с внешним outline, раскрытие меню с aria-expanded |
| Движение | переход цвета 180 ms; reduced-motion отключает переходы и плавный скролл |

Базовые компоненты: контейнер, секция, заголовок секции, eyebrow, primary/outline/light кнопки, текстовая ссылка с SVG, direction-card, product-media, configuration-card, module-card, таблица характеристик, контактный блок, header/footer.

Адаптация: 1200 px — уплотнение навигации и карточек; 1000 px — меню-кнопка; 700 px — одна колонка основных секций; 375 px — вертикальные действия и карточки модулей. Товарные фото используют `contain`, собственные пропорции и белую поверхность. Сценическое фото сохраняет полный кадр. Текст не перекрывает изображение робота.

## Развитие многостраничной версии

Главная представляет робототехнику в целом: изображение промышленного манипулятора, четыре направления, переход к сценариям. Yarbo представлен как одно из направлений. От Boston Dynamics и Universal Robots использован принцип продуктовой иерархии: короткое сообщение, крупное изображение, отдельные сценарии и сервис. Чужая айдентика и обещания не копируются.

Новые компоненты: editorial page-intro, editorial-card, brief-grid, FAQ, service-strip, галерея ракурсов, attachment-card, блок условий цены и таблица комплектующих. Ширина меню переключается на мобильный вариант ниже 1200 px. Сервисные карточки образуют сетку 2×2; товарные снимки используют contain. Таблица компонентов прокручивается внутри собственного контейнера на узком экране.
