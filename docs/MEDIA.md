# Медиа FutureKinetix

В репозитории хранятся изображения роботов Yarbo, навесного оборудования, логотипа и интерфейсных элементов сайта.

| Файл | Назначение |
| --- | --- |
| `module-plow.jpg` | Модуль отвала |
| `module-trimmer.jpg` | Модуль триммера |
| `module-blower.jpg` | Модуль воздуходувки |
| `module-mower.jpg` | Модуль газонокосилки |
| `module-snow.jpg` | Снегоуборочный модуль |
| `yarbo-core.jpg` | Yarbo Core |
| `yarbo-mower-pro.jpg` | Yarbo PRO для газона |
| `yarbo-snow-robot.jpg` | Yarbo-снегоуборщик |

Изображения выводятся с сохранением пропорций через `object-fit: contain`. Для кейсов страницы «О компании» используются иллюстративные фотографии инженерных и научных установок.
