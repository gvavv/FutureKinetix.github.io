## Найдено и исправлено

1. Главная 375 px: длинные названия в двухколоночной сетке увеличивали ширину документа. На телефоне введена одна колонка, для дочерних блоков задан `min-width:0`. Повторная проверка: 14/14 без горизонтального overflow.
2. Стрелки Unicode отображались квадратами в системном шрифте окружения. Заменены собственными SVG. Иконки областей применения также SVG.
3. Кнопка меню теряла доступное имя при скрытии подписи на телефоне. Добавлен постоянный `aria-label`. Открытие/закрытие, Escape и возврат фокуса проверены в браузере.
4. Мелкие метки первого экрана на узких ширинах увеличены до 12 px, служебная подпись логотипа скрыта на телефоне.
5. Формулировки о внутреннем этапе разработки убраны из покупательского контента продуктовой страницы.

## Итог

Просмотрены полные скриншоты и сравнительные листы всех ширин; отдельно крупно проверены desktop и узкий mobile. Изображения товара сохраняют пропорции, оборудование целиком в `contain`; зимнее фото не обрезается, текст расположен отдельно. Сетки перестраиваются без перекрытия, таблица помещается на 320 px, продуктовая навигация локально прокручивается горизонтально.

Автоматические результаты: [results.json](qa/results.json): нет битых изображений, ошибок JS, горизонтального переполнения документа и выходящих за экран заголовков/кнопок/изображений. Проверена сборка и локальные href/src. Проверены меню, Escape и копирование email. Контакты — рабочие `tel:` и `mailto:`; серверная отправка заявок не заявлена.

## Повторение проверки

После сборки запустить сервер по README, затем в окружении с Playwright и Chromium:

```sh
node docs/visual-qa.cjs
node docs/interactions.cjs
```

Playwright нужен только для проверки, не для сборки или работы сайта. Проверка проводилась в Chromium; Safari/iOS, Firefox и физические устройства в этот этап не входили. Новая версия не публиковалась.
