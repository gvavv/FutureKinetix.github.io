# Публикация FutureKinetix на GitHub Pages

Сайт — статический. GitHub Pages должен публиковать ветку main из корня репозитория.

## Файлы публикации

В корне репозитория должны находиться:

- index.html
- products.html
- yarbo.html
- automation.html
- company.html
- contacts.html
- styles.css
- site.js
- .nojekyll

Изображения-логотипы logo1.png, logo2.png и logo3.png можно оставить в репозитории для будущих материалов.

## Настройка GitHub Pages

1. Откройте Settings → Pages.
2. В поле Source выберите Deploy from a branch.
3. Укажите ветку main и папку / (root).
4. Сохраните настройки и дождитесь завершения workflow публикации.
5. Откройте ссылку, которую GitHub покажет в разделе Pages.

Проверка локального комплекта выполняется командой python3 build.py.

## Что проверить после публикации

- все шесть пунктов меню открываются;
- на мобильном экране появляется меню-бургер;
- на странице Yarbo работают комплектации, аксессуары и видеокарточки;
- видео загружаются с официального канала Yarbo и требуют доступа к YouTube;
- форма контактов открывает черновик письма на futurekinetix@ya.ru;
- цены Yarbo отображаются как ориентиры и подтверждаются менеджером перед заказом.

## Обновление

После правок проверьте комплект командой python3 build.py, затем закоммитьте изменённые файлы в main. GitHub Pages обновит сайт автоматически.
