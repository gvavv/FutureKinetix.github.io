# Хостинг FutureKinetix

Сайт состоит из шести статических HTML-страниц и двух общих ассетов. Серверная часть не требуется.

Для GitHub Pages используйте публикацию ветки main из корня репозитория. На другом статическом хостинге загрузите вместе:

- index.html
- products.html
- yarbo.html
- automation.html
- company.html
- contacts.html
- styles.css
- site.js
- .nojekyll

Перед публикацией выполните команду python3 build.py.

Форма контактов формирует письмо через почтовое приложение пользователя. Для серверной обработки заявок потребуется подключить внешний form endpoint и заменить обработчик в site.js.

Видеоматериалы Yarbo встроены через официальный YouTube-плеер. Для их просмотра посетителю нужен доступ к YouTube.
