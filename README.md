# FutureKinetix

Многостраничный статический сайт в ветке `codex/site-rebuild`. Новая версия не опубликована: публикация согласуется отдельно.

## Страницы

Главная · Yarbo и оснастка · Роботы · Индивидуальные решения · Гуманоиды · Установка и сервис · Компания · Контакты.

## Локальный запуск

Требуется Python 3, внешние зависимости для сборки не нужны:

```sh
python3 build.py
python3 -m http.server 4173 --directory dist
```

Открыть http://localhost:4173/. Сервер обслуживает все восемь страниц.

Шаблоны — в `src/`; каталог — в `data/products.json`; ценовые наблюдения — в `data/accessories.json`; стили и поведение — в `assets/site/`. После изменения повторить сборку. `dist/` исключён из Git; корневые HTML генерируются той же сборкой и сохраняют совместимость с GitHub Pages. Старые версии доступны в истории Git.
